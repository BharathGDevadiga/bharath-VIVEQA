# Sentinel-RV: Verification & Results

This directory contains critical timing reports, hardware visualizations, and simulation artifacts generated by Vivado across the RTL, Synthesis, and Implementation pipeline.

## 📊 Performance Summary
* **Target Device:** Xilinx Artix-7 `XC7A35T-FTG256-1`
* **Status:** 🟢 **0 Errors, 0 Critical Warnings**
* **Worst Negative Slack (WNS):** +14.744 ns (Met 24 MHz target)
* **Total Hold Slack (THS):** +0.082 ns
