## 📂 Verification Artifacts & Hardware Visuals

This directory is organized into four distinct stages of the FPGA design flow, containing high-resolution exports that document the physical and logical structure of the processor.

### 1. RTL Design (`1_rtl/`)
* **`rtl_schematic.pdf`**: High-level structural view showing how the Verilog modules (CPU, Memory, Security Core, Peripherals) are instantiated and wired together before any optimization.

### 2. Synthesis (`2_synthesis/`)
* **`synthesis_schematic.pdf`**: The post-synthesis netlist showing how the RTL was mapped into technology-independent logic primitives.
* **`synthesis_device.png`**: Preliminary visual representation of the un-routed design mapped onto the Artix-7 silicon die.
* **`synthesis_package.png`**: Preliminary diagram showing the physical XC7A35T BGA package assignments.

### 3. Implementation (`3_implementation/`)
* **`implementation_schematic.pdf`**: The final, fully-optimized netlist schematic after placement and routing.
* **`implementation_device.png`**: The final silicon die layout, highlighting exact physical routing and resource utilization (BRAMs and logic slices).
* **`implementation_package.png`**: The final physical BGA package pinout showing exactly which pins the I/O ports (UART, Relay, SD Card, etc.) are constrained to.

### 4. Simulation (`4_simulation/`)
* **`simulation_waveforms.pdf`**: Icarus Verilog/Vivado behavioral simulation waveforms demonstrating the exact cycle-by-cycle execution of the security controller, anti-replay nonces, and AES encryption.
