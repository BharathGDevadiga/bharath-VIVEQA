# Synthesis Phase

This directory contains the post-synthesis visual artifacts generated by Vivado after mapping the RTL design to technology-independent logic primitives.

## Included Files
* **`synthesis_schematic.pdf`**: The post-synthesis netlist showing how the RTL was mapped into LUTs, Flip-Flops, BRAMs, etc.
* **`synthesis_device.png`**: Preliminary visual representation of the un-routed design mapped onto the Artix-7 silicon die.
* **`synthesis_package.png`**: Preliminary diagram showing the physical XC7A35T BGA package assignments.
