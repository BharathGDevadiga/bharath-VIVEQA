# Sentinel-RV: Synthesis, Implementation & Verification Results

Welcome to the **`result/`** directory. This folder contains all the critical timing reports, hardware visualizations, and verification artifacts generated by Vivado during the synthesis, implementation, and simulation of the Sentinel-RV SoC.

## 📂 Verification Artifacts & Hardware Visuals

This directory contains several high-resolution exports that document the physical and logical structure of the processor.

### 1. Hardware Schematics
* **`rtl_schematic.pdf` / `.svg`**: High-level RTL structural view showing how the Verilog modules (CPU, Memory, Security Core, Peripherals) are instantiated and wired together before optimization.
* **`synthesis_schematic.pdf` / `.svg`**: The post-synthesis netlist showing how the RTL was mapped into physical FPGA primitives (LUTs, Flip-Flops, BRAMs, and DSPs).
* **`sentinel_rv_architecture.jpg`**: A high-level system architecture and peripheral interconnect diagram.

### 2. Device & Package Pinouts
* **`device_layout.pdf` / `.png`**: Visual representation of the routed design mapped onto the actual Artix-7 silicon die, highlighting resource utilization (BRAMs and logic slices).
* **`package_pinout.pdf` / `.png`**: Diagram showing the physical XC7A35T BGA package and exactly which physical pins the I/O ports (UART, Relay, SD Card, etc.) are constrained to.

### 3. Simulation & Telemetry
* **`simulation_waveforms.pdf`**: Icarus Verilog/Vivado behavioral simulation waveforms demonstrating the exact cycle-by-cycle execution of the security controller, anti-replay nonce generation, and AES encryption logic.
* **`sensor_telemetry_log.csv`**: A recorded log of live, encrypted telemetry streaming data captured over the USB/UART interface at 115200 baud.
