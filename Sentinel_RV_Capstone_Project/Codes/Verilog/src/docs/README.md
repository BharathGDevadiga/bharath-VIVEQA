# Sentinel-RV Technical Subsystem Specifications

This directory contains technical documentation markdown files providing architectural overviews for all active hardware subsystems.

---

### 📌 Included Subsystem Specifications:
* **`ADC.md`**: Analog-to-Digital converter interface specification.
* **`Integration.md`**: System integration and peripheral bus topology.
* **`LCD.md`**: Character LCD display driver specification.
* **`Relay.md`**: Relay safety isolation driver specification.
* **`SDCARD.md`**: SPI SD card audit log writer specification.
* **`SPI.md`**: Serial Peripheral Interface master controller specification.
* **`UART.md`**: Serial communication and telemetry protocol specification.
