# Sentinel-RV Technical Subsystem Specifications

This directory contains technical documentation markdown files providing architectural overviews for all hardware subsystems.

---

### 📌 Included Documentation:
* **ADC.md**: Analog-to-Digital converter interface spec.
* **ESP32.md**: Wireless gateway communication spec.
* **Integration.md**: System integration and peripheral bus topology.
* **LCD.md**: Character LCD display driver spec.
* **Motor.md**: Historical actuator driver spec.
* **Relay.md**: Relay safety isolation driver spec.
* **SDCARD.md**: SPI SD card audit log writer spec.
* **SPI.md**: Serial Peripheral Interface master controller spec.
* **UART.md**: Serial communication and telemetry protocol spec.
